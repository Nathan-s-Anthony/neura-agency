# Agency Agent Registry

The Agent Registry defines the specialized agents available to the
AI Agency.

Each agent has a defined responsibility, capabilities, inputs,
outputs, and limitations.

## Registered Agents

### Client Agent

Role:
Client discovery and project intake.

Primary responsibility:
Understand the client's problem and transform the initial request
into a structured project brief.

---

### Tech Lead Agent

Role:
Technical leadership and project architecture.

Primary responsibility:
Translate the project brief into a technical strategy,
architecture, requirements, and implementation plan.

---

### Lead Developer Agent

Role:
Software implementation.

Primary responsibility:
Implement approved technical plans and development tasks.

---

### Marketing Agent

Role:
Marketing strategy and positioning.

Primary responsibility:
Understand the target market, positioning, audience, and
go-to-market requirements.

---

### Copywriter Agent

Role:
Written communication and content.

Primary responsibility:
Create client-facing and product-facing written content.

---

### QA Agent

Role:
Quality assurance and validation.

Primary responsibility:
Verify that project outputs satisfy requirements and quality
standards.
