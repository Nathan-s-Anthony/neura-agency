# Project Lifecycle

## Purpose

The Project Lifecycle defines how the AI Agency transforms an
initial client idea or problem into a completed software product.

The lifecycle provides the high-level workflow through which
projects move between agency stages.

---

## Lifecycle

A project generally progresses through the following stages:

1. Intake
2. Discovery
3. Planning
4. Specialist Work
5. Development
6. Quality Assurance
7. Delivery

The lifecycle is not necessarily strictly linear.

Stages may return to previous stages when new information,
requirements, defects, or changes are discovered.

---

## Stage 1 — Intake

Purpose:

Capture the initial client request and create a project record.

Primary Agent:

Client Agent

Inputs:

- Client idea
- Client problem
- Client request

Outputs:

- Initial project record
- Initial project description

Transition:

Intake → Discovery

---

## Stage 2 — Discovery

Purpose:

Understand the problem the client is attempting to solve.

Primary Agent:

Client Agent

Activities:

- Identify the underlying problem.
- Identify target users.
- Identify desired outcomes.
- Identify functional requirements.
- Identify constraints.
- Identify unknown information.
- Identify assumptions.

Outputs:

- Project brief
- Requirements
- Assumptions
- Open questions
- Initial capability requirements

Transition:

Discovery → Planning

If critical information is missing:

Discovery → Client

---

## Stage 3 — Planning

Purpose:

Transform the project brief into an executable plan.

Primary Agent:

Tech Lead Agent

Activities:

- Analyze requirements.
- Define architecture.
- Select appropriate technologies.
- Identify integrations.
- Identify technical risks.
- Define development tasks.
- Define dependencies.
- Define acceptance criteria.
- Identify required specialist agents.

Outputs:

- Architecture
- Technical decisions
- Development plan
- Task breakdown
- Agent assignments

Transition:

Planning → Specialist Work
Planning → Development

---

## Stage 4 — Specialist Work

Purpose:

Complete non-development work required by the project.

Possible Agents:

- Marketing Agent
- Copywriter Agent
- Designer Agent
- Research Agent

Specialist work may occur before, during, or after development
depending on project requirements.

Outputs:

- Marketing strategy
- Content
- Design specifications
- Research
- Other specialist deliverables

Transition:

Specialist Work → Development

---

## Stage 5 — Development

Purpose:

Implement the approved technical plan.

Primary Agent:

Lead Developer Agent

Activities:

- Implement features.
- Implement APIs.
- Implement database changes.
- Implement frontend functionality.
- Write tests.
- Refactor code.
- Resolve development issues.

Outputs:

- Working software
- Automated tests
- Development documentation

Transition:

Development → Quality Assurance

If requirements or architecture need significant changes:

Development → Planning

---

## Stage 6 — Quality Assurance

Purpose:

Verify that the implementation satisfies project requirements.

Primary Agent:

QA Agent

Activities:

- Execute tests.
- Validate acceptance criteria.
- Identify defects.
- Test edge cases.
- Perform regression testing.

Outputs:

- QA report
- Defect reports
- Validation result

Transitions:

QA → Delivery

or

QA → Development

if defects are discovered.

---

## Stage 7 — Delivery

Purpose:

Prepare the completed project for delivery to the client.

Activities:

- Confirm requirements have been satisfied.
- Confirm QA approval.
- Prepare documentation.
- Prepare deployment.
- Obtain required human approval.
- Deploy or deliver the application.

Human approval:

Required before production deployment or other consequential
external actions.

Outputs:

- Completed project
- Deployment
- Client deliverables

---

## Lifecycle Completion

A project is considered complete when:

- Requirements have been satisfied.
- Required specialist work has been completed.
- Development has been completed.
- QA has approved the implementation.
- Required documentation exists.
- Required human approvals have been obtained.
- The application has been delivered or deployed.
