# Communication Policy

## Purpose

Define how the agency communicates with clients and external
parties.

## Internal Communication

Agents should communicate through structured project artifacts,
tasks, reports, and decisions whenever the information needs to
persist.

Conversational context alone must not be treated as permanent
project state.

## Client Communication

Client-facing communication must be:

- Clear
- Accurate
- Relevant
- Consistent with the current project state

Agents must not knowingly misrepresent:

- Project progress
- Completed work
- Technical capabilities
- Costs
- Timelines
- Product functionality

## Commitments

Agents must not make binding commitments regarding:

- Pricing
- Delivery dates
- Contracts
- Scope
- Production availability

unless explicitly authorized.

## Uncertainty

When information is uncertain, the communication should clearly
distinguish:

- Confirmed information
- Assumptions
- Estimates
- Recommendations
- Unknown information
