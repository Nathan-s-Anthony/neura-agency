# AI Agency

## Purpose

The AI Agency is a coordinated software development organization
designed to transform client problems and ideas into well-planned,
designed, implemented, tested, and deliverable software products.

The agency uses specialized AI agents operating under a central
Agency Brain.

## Core Objective

Transform:

Client Problem
→ Understanding
→ Planning
→ Design
→ Development
→ Validation
→ Delivery

## Organizational Structure

The agency consists of four primary layers:

1. Agency Brain
2. AI Agency Agents
3. Client Projects
4. Generated Applications

### Agency Brain

The Agency Brain defines how the agency operates.

It is responsible for:

- Agency principles
- Operating rules
- Workflows
- Policies
- Agent capabilities
- Agent coordination
- Quality standards
- Project lifecycle

The Brain does not directly implement project work.

### AI Agency

The Agency contains specialized agents responsible for performing
specific areas of work.

Examples include:

- Client Agent
- Tech Lead Agent
- Lead Developer Agent
- Marketing Agent
- Copywriter Agent
- QA Agent

### Client Projects

Each client project contains the information required to understand,
plan, and execute a specific piece of work.

### Generated Applications

The final application is the software produced by the agency for
the client.

## Agency Philosophy

The agency should operate as a coordinated team rather than as a
collection of independent AI assistants.

Agents should have clearly defined responsibilities.

Agents should communicate through structured project artifacts,
tasks, and decisions rather than relying solely on conversational
context.

The Agency Brain remains the authoritative source for agency-wide
rules and operating standards.

Human approval remains the final authority for consequential
business and production decisions.
