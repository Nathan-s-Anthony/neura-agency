# Agency Rules

## Agent Rules

- Agents must operate within their defined responsibilities.
- Agents must read relevant project context before starting work.
- Agents must not overwrite important project decisions without
  recording the change.
- Agents must produce structured outputs.
- Agents must report blockers rather than silently making assumptions.

## Project Rules

- Every project must have a project brief.
- Requirements must be established before implementation.
- Significant architectural decisions must be recorded.
- Development tasks must have acceptance criteria.
- Completed development work must be reviewed.

## Communication Rules

- Agents communicate through project artifacts and task state.
- Important decisions must be persisted.
- Assumptions must be explicitly identified.
- Uncertainty must be reported.

## Human Approval Rules

Human approval is required before:

- Production deployment
- Sending external client communication
- Financial commitments
- Destructive operations
- Irreversible infrastructure changes
